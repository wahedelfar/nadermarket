## 🚀 البدء السريع

### المتطلبات
- Node.js 18+
- npm أو pnpm
- قاعدة بيانات MySQL/TiDB

### خطوات التثبيت

```bash
# 1. استنساخ المشروع
git clone <repository-url>
cd nader-market-web

# 2. تثبيت المتطلبات
pnpm install

# 3. إعداد متغيرات البيئة
# أنشئ ملف .env وأضف:
# DATABASE_URL=your_database_url
# JWT_SECRET=your_secret_key
# VITE_APP_ID=your_app_id
# OAUTH_SERVER_URL=your_oauth_url

# 4. إعداد قاعدة البيانات
pnpm db:push

# 5. تشغيل المشروع
pnpm dev
```

## 🗂️ هيكل المشروع

```
nader-market-web/
├── client/                 # الواجهة الأمامية (React)
│   ├── src/
│   │   ├── pages/         # صفحات التطبيق
│   │   ├── components/    # مكونات قابلة لإعادة الاستخدام
│   │   ├── contexts/      # React Contexts
│   │   └── lib/           # مكتبات مساعدة
│   └── public/            # ملفات ثابتة
├── server/                # الخادم الخلفي (Express + tRPC)
│   ├── routers.ts         # مسارات tRPC
│   ├── db.ts              # دوال قاعدة البيانات
│   └── _core/             # ملفات النواة
├── drizzle/               # تكوين قاعدة البيانات
│   ├── schema.ts          # تعريف الجداول
│   └── migrations/        # ملفات الهجرة
├── shared/                # الكود المشترك
└── package.json           # المتطلبات والإعدادات
```

## 🛠️ التكنولوجيا المستخدمة

### الواجهة الأمامية
- **React 19** - مكتبة واجهة المستخدم
- **Tailwind CSS 4** - إطار عمل CSS
- **TypeScript** - لغة البرمجة
